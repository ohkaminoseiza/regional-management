# コンパクトシティ計画と産業クラスター政策の制度的接合——2026年都市再生特別措置法等改正の地域経営論的読解

## 2. 要点（3つ）

**① 立地適正化計画の誘導対象に「特定業務施設」を追加**

2014年の制度化以来、立地適正化計画（コンパクト・プラス・ネットワーク）は医療・福祉・商業等の「都市機能」と「居住」の配置誘導を担う計画として運用されてきた。2026年改正では産業系の「特定業務施設」（半導体・AI関連施設やデータセンター等が想定される）を立地誘導の対象に組み込むことが可能となった。これにより内閣官房「地域未来戦略本部」が推進する戦略産業クラスター計画と、国土交通省が所管するコンパクトシティ計画（立地適正化計画）が制度的に接合され、産業立地と居住・都市機能の配置を同一計画体系のなかで論じる構造が生まれる。

**② 都道府県への立地適正化計画に関する市町村間調整権限の新設**

従来、立地適正化計画は各市町村が独立して策定する計画であり、隣接自治体間で方針の齟齬が生じても調整する制度的回路に乏しかった。本改正では都道府県が複数市町村の立地適正化計画を調整する権限を付与される。広域的な産業集積・物流・インフラ整備と基礎自治体の土地利用計画を整合させるうえで不可欠な変更とされており、地域未来戦略が構想する「都道府県知事主導の産業クラスター計画」とも方向性が一致する。

**③ エリアマネジメント計画制度の創設と民間投資誘致のインセンティブ強化**

地域の歴史・文化・景観・環境に根ざした「個性ある都市空間」を推進する観点から、エリアマネジメント活動に関する計画制度が創設された。あわせて、民間の公共貢献に対する容積率緩和の適用対象をオフィスビルやアリーナ等に拡大する措置が含まれているとされる（詳細は未確認）。

## 3. 「地域経営」の観点から見た意味

地域経営の実践において「何を、どのスケールで、誰が計画するか」という問いは根本的な問題である。今回の改正はこの問いに二つの重要な変更を加えた。

第一は計画対象の拡張である。従来の立地適正化計画は「暮らしの場の適正配置」という社会的厚生の最適化を主眼としていたが、特定業務施設が加わることで「暮らしと産業の複合的配置」へと計画の論理が拡張する。産業立地政策（地域未来戦略）と都市空間計画（立地適正化計画）が同一の制度言語で語られるようになる転換点として記録しておく価値がある。

第二はガバナンス構造の変容である。都道府県への市町村間調整権限の付与は、コンパクトシティ政策において「市町村自律型」から「都道府県主導の広域調整型」へと重心が移行することを意味する。これは地域未来戦略の「知事主導クラスター計画」という政策設計とも一致しており、都道府県が地域経営の実質的な主体として浮上しつつある政策転換の一側面として位置づけられる。

## 4. 考察

コンパクトシティ政策は2000年代以降の日本の都市計画において、人口減少・財政制約への対応として確立されてきた。その理念的中核は「集約と効率化」——人口と都市機能を一定のエリアに誘導し、公共サービスの持続可能性と居住環境の質を両立させる——という社会的厚生の最適化にある。2014年の立地適正化計画制度化はその制度的結実であった。

しかし2026年改正は、この計画枠組みに「産業立地」という本質的に異なる論理を接合した点で注目に値する。産業立地は利益最大化・競争力強化の論理に従い、必ずしも「コンパクトな市街地内」「居住地の近傍」という空間原則と整合するわけではない。半導体工場やデータセンターは大規模な用地・安定したインフラ・低地価を求め、都市縁辺部や農業地域への立地を選好することが多い。こうした産業論理をコンパクトシティの計画体系に収めようとする試みは、従来の計画概念の内部矛盾を孕む可能性がある。

理論的には、この改正は都市計画論における「計画の多目的性と整合性」という古典的問題を再浮上させる。居住・商業・福祉・産業という互いに異なる合理性基準をもつ土地利用を一つの計画体系で扱おうとすれば、調整コストの増大は避けられない。都道府県への調整権限付与はこの問題への実務的解答として評価できるが、それが「計画の真の統合」をもたらすのか、あるいは「調整コストの階層移転」に留まるのかは、今後の実証研究が問うべき論点である。特に、産業集積の利益が特定地域に集中する一方で、コンパクト化の恩恵が薄れる周辺市町村をいかに計画体系のなかに包摂するかは、地域間衡平の観点から重要な研究課題となる。

加えて、エリアマネジメントや民間投資誘致の仕組みは、すでに民間開発需要がある都市部・投資拠点型地域では有効に機能しうるが、人口流出が続く地方中小都市や過疎地域ではこれらの制度を活用できる民間主体そのものが不在となる。「制度の整備」と「制度を使いこなせる地域の実力」との乖離は地域経営論が繰り返し直面してきた問題であり、本改正もその構造的限界の外にはない。法改正の施行後、立地適正化計画の改訂状況・産業施設の誘導実績・都道府県による調整事例の蓄積を追跡することが、地域計画研究における次の重要な実証課題となろう。
