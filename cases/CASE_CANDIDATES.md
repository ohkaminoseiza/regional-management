# ケースノート候補台帳

「地域経営ケースノート」の執筆候補を蓄積するための台帳。
**毎週は執筆、月1回は仕入れ** という運用を前提とする。

## この台帳の性格（重要）

ここに記載された地域名・事業名・時期は、**検証済みの事実ではなく「調査の出発点」**である。
実際にケースノートを執筆する際は、必ず自治体の公式資料・議会資料・事業計画・
国の事例集などの一次資料まで遡り、年月・金額・組織数を確認すること。
台帳の記載と一次資料が食い違う場合は、**一次資料を優先**する。
確認できない事項は推測で補わず、記事中に「資料上確認できなかった」と明記する。

なお、著名な事例ほど二次的な紹介記事が多く流通しており、
そこでは初期の構想段階の説明がそのまま現在の説明として反復されている場合がある。
「いつの時点の情報か」を常に確認すること。

## 対象領域（8分野）

1. 地域運営組織・住民自治
2. 中心市街地・商店街再生
3. 公共施設・遊休資産活用
4. 河川・港湾・ウォーターフロント
5. 公共交通・地域モビリティ
6. 空き家・住宅・移住定住
7. 地域産業・観光・文化
8. デジタル化・データ活用

## 地方区分

北海道 / 東北 / 関東 / 中部 / 近畿 / 中国 / 四国 / 九州・沖縄

直近8〜12週で同じ地方・同じ分野が続かないよう配慮する。
ただし均等配分を絶対条件とはせず、**資料の信頼性と充実度を優先**する。

## 選定スコア（14点満点・9点以上を掲載候補とする）

| 評価項目 | 配点 |
|---|---|
| 公式一次資料が複数ある | 0〜2 |
| 5年以上の経過を確認できる | 0〜2 |
| 実施主体・役割分担が明確 | 0〜2 |
| 財源・制度を確認できる | 0〜2 |
| 成果と課題の双方を確認できる | 0〜2 |
| 地域経営論上の問いがある | 0〜2 |
| 最近取り上げた地域・分野と重複しない | 0〜2 |

「有名だから選ぶ」のではなく、**ケースとして分析できる資料がそろっているか**を基準とする。
順調に見える事例だけでなく、計画の見直し・縮小・撤退を経た事例も積極的に対象とする。

## 候補発見の入口

### 第1の入口：国の事例集・採択事例
- 内閣府・内閣官房（地方創生、地域未来戦略）
- 総務省（地域運営組織、過疎対策、特定地域づくり事業）
- 国土交通省（かわまちづくり、官民連携、都市再生、空き家対策モデル事業）
- 経済産業省・中小企業庁（地域経済、商店街、地域企業）
- デジタル庁（地域幸福度・Well-Being指標の活用事例）
- 農林水産省（農村RMO、地域資源活用）
- 文化庁（文化財活用、文化観光）

### 第2の入口：全国組織・公的研究機関
- 全国市長会、全国町村会
- 地方自治研究機構、自治体国際化協会
- 国土交通政策研究所
- 国立国会図書館の調査資料
- 都市再生機構ほか公的機関

### 第3の入口：受賞・認定制度（発見の手がかりとしてのみ用いる）
- まちづくり・都市景観関連の表彰
- 地方創生関連の表彰
- グッドデザイン賞（公共・地域分野）
- 土木学会賞、日本都市計画学会賞
- 地域づくり表彰

**受賞の事実それ自体を成果の証明として扱わない。** 候補発見の入口としてのみ用い、
実際の執筆では一次資料に遡る。
